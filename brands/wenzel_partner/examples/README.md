# Examples

This folder contains reusable sample outputs for the Wenzel & Partner brand package.

Recommended examples:
- instagram_listing_launch.md
- property_description.md
- email_opening.md
- reel_script.md

## Example Standard
Examples should demonstrate:
- premium tone
- clear brand positioning
- platform-specific formatting
- reusable placeholders where possible

## Multi-Brand Rule
Examples should be brand-specific at the content layer but built from reusable templates so future brand folders can follow the same structure.
