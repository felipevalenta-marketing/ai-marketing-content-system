# Knowledge Base

This folder stores reusable brand knowledge for Wenzel & Partner.
The content is structured for AI-readable ingestion, human review, and future brand reuse.

## Folder Structure

- `market/` market context, positioning, and macro notes
- `properties/` property types, listing attributes, and asset facts
- `services/` service offerings, process notes, and client experience
- `neighborhoods/` location profiles and area intelligence
- `brand_story/` brand narrative, heritage, and proof points
- `content_examples/` reusable content samples and prompt-ready references
- `competitors/` competitive positioning and differentiation notes

## Usage Pattern

Keep knowledge factual, concise, and easy to update.
The core engine should read these files as data, not as instructions.

Recommended file rules:
- one topic per file
- short paragraphs
- consistent headings
- no marketing fluff without evidence
- no hidden assumptions

## Multi-Brand Rule

Each brand should have its own knowledge base so future brands can swap markets, services, and competitive context without changing shared code.
