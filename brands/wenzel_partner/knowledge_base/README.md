# Knowledge Base

This folder stores reusable brand knowledge that can be loaded into prompts or content pipelines.

Recommended markdown entries:
- market_overview.md
- service_areas.md
- faq.md
- proof_points.md
- compliance_notes.md

## Usage Pattern
Keep knowledge factual, concise, and easy to update.
The core engine should read these files as data, not as instructions.

## Multi-Brand Rule
Each brand should have its own knowledge base so future brands can swap markets, services, and compliance notes without changing shared code.
