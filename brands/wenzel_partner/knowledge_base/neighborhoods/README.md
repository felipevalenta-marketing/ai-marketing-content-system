# Mallorca Regional Storytelling

## Purpose
This folder contains the Mallorca regional knowledge layer for Wenzel & Partner.
It is designed to support AI-readable, reusable, multi-brand real estate storytelling.

## Regional Architecture

### Palma Core
Used for urban, lifestyle-led, and premium city positioning.
- `palma.md`
- `santa_catalina.md`
- `palma_old_town.md`
- `portixol.md`
- `el_terreno.md`

### Northeast Mallorca
Used for authentic, scenic, and character-driven storytelling.
- `arta.md`
- `cala_ratjada.md`

### Southeast Mallorca
Used for Mediterranean living, second-home narratives, and coastal or village positioning.
- `Sant_Llorenç_des_Cardassar.md`
- `son_maciá.md`
- `porto_cristo.md`
- `cala d´or.md`

## Higher-Level Storytelling Layer

### Palma Urban Lifestyle
Palma should be framed as a refined urban base where buyers can combine city living, dining, culture, convenience, and year-round usability.

### Northeast Authentic Mallorca
The northeast should communicate authenticity, landscape, calmer rhythms, and a more rooted Mallorca identity.

### Southeast Mediterranean Living
The southeast should highlight beach access, relaxed coastal living, holiday-home appeal, and flexible lifestyle use.

### Tramuntana Luxury Nature Lifestyle
The Tramuntana should be positioned as premium nature-led living with privacy, views, architecture, and retreat energy.

## Usage Pattern

Use these regional files to inform:
- area guides
- property descriptions
- relocation copy
- SEO content
- social captions
- campaign storytelling

## File Rules

- one location or region per file
- short, scannable headings
- concrete language only
- no generic destination copy
- no hardcoded business logic

## Multi-Brand Rule

This regional layer should remain portable across brands and markets.
Shared systems should treat the content as branded knowledge, not application logic.
